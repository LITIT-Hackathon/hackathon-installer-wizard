# Reference Product

LITIT AI Desktop is a fictional local AI application.

The product consists of:

- Desktop application
- Local backend service
- Local AI model
- Microphone integration

Users currently install these components manually.

This results in frequent setup failures caused by:

- unsupported operating systems
- insufficient disk space
- missing Python installation
- unavailable microphone permissions
- missing or incompatible GPU/CUDA
- incorrectly configured model paths

Your task is to improve this installation experience.
