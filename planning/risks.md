# Risks

| Risk | Likelihood / impact | Mitigation | Trigger / fallback |
|---|---|---|---|
| Tauri/Rust packaging learning consumes sprint | M/H | time-box early shell + command spike | cannot package/run health by hour 4 → demo dev shell or Electron while keeping ports |
| Reference asset layout fails health | H/H | installation contract test creates `models/` | health says model missing → fix copy mapping, never mask it |
| Cross-platform scope dilutes working demo | H/H | one real OS, explicit mocks for rest | adapter slips → preserve profile demo |
| Automatic remediation damages environment | M/H | simulate; preview; no CUDA/global mutation | uncertain change → manual/CPU fallback |
| Fake progress or research claims undermine trust | M/H | real events/indeterminate mode; label simulation | unknown duration/evidence → state unknown honestly |
| Permissions/proxy discovered late | M/H | preflight and mock profiles | blocked native action → export/manual path |
| Accessibility postponed | H/M | semantic components from first slice | keyboard path fails → cut decorative/P2 work |
| Health result parsing brittle | M/H | structured JSON + exit contract tests | invalid output → diagnostic failure with raw evidence |
| Demo failure due to machine variance | M/H | deterministic mock profiles plus real-contract smoke test | native scan differs → switch labeled demo profile |
| Sensitive diagnostics exported | L/H | redaction allowlist, review fixture | unknown field → omit by default |

Owners: Frontend Architect (shell/contracts), UX Lead (content/a11y), Delivery Lead (scope/demo), Product/technical owner (manifest/runtime policy).
