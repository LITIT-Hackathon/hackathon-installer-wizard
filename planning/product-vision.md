# Product vision

For people installing LITIT AI Desktop across personal, development, and managed machines, Smart Install is an environment-aware desktop wizard that explains compatibility, protects existing setups, guides recovery, and proves the product works. Unlike a wrapper around scripts, it makes machine evidence, planned changes, and verification understandable at the level each user needs.

## Principles of value

- Detect facts; do not make users translate their machine into a form.
- Prevent expensive or risky work before it starts.
- Provide safe defaults without hiding control.
- Treat recovery and verification as first-class product behavior.

## Measures

MVP: all five supplied profiles produce the correct classification; a deliberate blocker can be recovered without restart; health failure identifies an actionable item; keyboard happy/failure paths work; the demo completes reliably. Future: task success, recovery rate, time, confidence, support-bundle usefulness, and unintended-environment-change rate with real users.
