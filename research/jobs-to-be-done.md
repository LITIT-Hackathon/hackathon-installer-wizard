# Jobs to be done

> **Research basis:** simulated persona sessions and supplied repository evidence; future interviews must validate importance and wording.

## Functional jobs

- When I install LITIT AI Desktop on a new machine, I want the installer to verify whether my environment is suitable, so that I know the product will work before large files are installed.
- When a prerequisite fails, I want an appropriate fix or alternative and a scoped recheck, so that I can continue without restarting.
- When I use a configured development/ML machine, I want existing runtimes preserved, so that this product does not break other work.
- When storage is constrained, I want to choose and validate application/model locations separately, so that installation does not fail late.
- When I manage endpoints, I want a reviewable, repeatable change plan and diagnostic record, so that I can comply with policy.
- When installation finishes, I want a real health check and launch proof, so that I know the application—not only the installer—works.

## Emotional jobs

- Feel informed rather than intimidated by technical checks.
- Feel in control of consequential machine changes.
- Feel confident that progress is real and recovery is possible.
- Avoid anxiety that an installer will damage an existing environment.

## Social and organizational jobs

- Provide support or IT with evidence they can act on.
- Demonstrate that the installation is auditable and policy-aware.
- Avoid appearing careless with company security, storage, or developer tooling.
- Reproduce an approved installation across machines.
