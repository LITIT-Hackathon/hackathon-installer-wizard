# Standalone Remotion demo prompt

```text
Create a 75–90 second 16:9 Remotion product demo video for “Smart Install,” an intelligent installer wizard for LITIT AI Desktop. Deliver React/Remotion scene structure, timing, transitions, captions, and voiceover script. The visual tone is professional, calm, technical, and enterprise-ready: neutral light UI, restrained blue action color, semantic statuses, crisp desktop framing, minimal shadows, no glassmorphism, excessive gradients, playful motion, or fake terminal theatrics. Use reduced, purposeful 150–200 ms transitions and readable captions.

Tell a reasoning-led story, not a feature montage:
0–8s Problem: “Installation fails long before users know why.” Show four concise persona tensions: simplicity, exact control, enterprise policy, CUDA preservation.
8–16s Scan: launch Smart Install and automatically check OS, memory, disk, Python, microphone, and optional GPU/CUDA. Show named status changes; do not invent percentages.
16–28s Failure: Python is deliberately missing. Show a blocking result in plain language: what is needed, why, and the next action. Expand Technical details to reveal exact detection evidence.
28–39s Recovery: preview a clearly labeled simulated safe remediation, apply it, then rerun only Python. Animate failed → checking → remediated/passed while every other result stays intact. Caption: “Recovery without starting over.”
39–50s Control: select separate app/model locations, show space, choose CPU mode without changing an existing CUDA environment, then review a plan listing files, size, permissions, network, and environment impact.
50–65s Install: show truthful named operations—create directories, copy application, place model at models/demo-model.bin, write/preserve config, verify assets. Use determinate progress only if data is known.
65–78s Proof: run product health checks for config, model, microphone, backend, overall status; show successful structured results and launch LITIT AI Desktop.
78–90s Outcome: “The installer understands my computer.” Show a compact traceability overlay: user need → UX decision → component → behavior, plus “One real platform + deterministic cross-platform profiles for MVP.”

Accessibility: captions remain on screen long enough, text contrast meets WCAG AA, meaning never depends on color alone, avoid rapid flashes, and include a reduced-motion render option. Clearly label simulated profile/remediation footage. Do not claim real interviews: use “simulated persona-based research.” Do not claim all-platform native support. Include audio cues sparingly, export settings for 1920×1080 at 30 fps, and define reusable scene components for BrowserFrame, Cursor, StatusCheck, Callout, Caption, ProgressOperation, HealthResult, and TraceabilityRow.
```
