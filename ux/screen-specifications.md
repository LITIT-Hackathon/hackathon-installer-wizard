# Screen specifications

All screens use the stepper, keyboard order matching visual order, non-color status labels/icons, and contextual technical details. “Advanced” content remains reachable and copyable.

| # / Screen | Purpose / personas | Actions | Visible / advanced information | Errors and accessibility |
|---|---|---|---|---|
| 01 Welcome | set expectations; primary Business, all secondary | **Analyze this computer**; exit | local checks, time/privacy; advanced manifest/version | manifest load alert; focus on heading, concise scope |
| 02 System Scan | show credible detection; all | **View report** when complete; cancel | named checks and live state; paths/commands advanced | per-check unknown/retry; polite live announcements, reduced motion |
| 03 Compatibility Overview | support decision; primary Business/IT | **Continue**; rescan | overall result and grouped requirements; evidence advanced | error summary links to checks; status not color-only |
| 04 Blocking Requirement Failure | recover within report; persona varies | **Apply recommended fix** or **Re-check**; manual/help | cause, impact, change scope; command/output advanced | CTA disabled until valid; focus moves to result, not top of page |
| 05 Optional Remediation Warning | inform without blocking; primary ML/Developer | **Use safe fallback**; keep current/manual | current vs expected and consequences; compatibility detail advanced | warning is not styled/announced as error; explicit acknowledgment |
| 06 Configuration | choose destinations/mode; Developer/ML primary | **Review installation**; back | recommended application/model paths and mode; port/config advanced | inline errors plus summary; native picker has text alternative |
| 07 Installation Summary | informed consent; IT primary | **Install**; edit/export plan | components, sizes, paths, downloads, privileges, changes; hashes advanced | unresolved blocker links backward; confirmation text names impact |
| 08 Installation Progress | communicate durable work; all | **Cancel** if safe; diagnostics | phase, item, bytes/percent where known; event log advanced | interruption becomes recoverable state; progress semantics/live throttling |
| 09 Installation Failure + Retry | recover smallest unit; Developer primary | **Retry failed step**; change settings/export | plain cause, retained progress, next action; raw error advanced | focus error heading; no automatic countdown/retry |
| 10 Health Check | prove product operation; all | **Run checks** / **Retry failed check**; diagnostics | config, model, microphone, backend/product status; JSON advanced | each item actionable; announced summary after completion |
| 11 Success | close confidently; Business primary | **Open LITIT AI Desktop**; view summary | installed version/location and verified checks; record advanced | launch failure returns to verification; clear focus/exit behavior |
| 12 Advanced Diagnostics | support expert/IT work | **Copy** / **Export support bundle**; close | filters, timestamps, severity, source; raw output | redact secrets, selectable text, no terminal-only semantics |

## Screen-level evidence traceability

Compatibility and failure screens answer Business comprehension; technical disclosure answers Developer/ML evidence needs; the plan and export answer IT audit needs; scoped retry answers all four; health proof directly uses the supplied product contract.
